# 커뮤니티 한줄광고

커뮤니티 카테고리에 추가되는 **한줄광고** 섹션의 프론트엔드 프로토타입입니다.
외부 라이브러리 없이 단일 `index.html`로 동작하며 PC·모바일 반응형입니다.

- 배포 URL: https://bobae-art.github.io/ad/
- 가격: 1일 110,000원, 신청 시 1·2·3일 선택 (셀렉트박스)

## 흐름

1. **광고 신청** (`#/new`) – 광고 문구(40자) · 링크 · 광고주명 · 연락처 · 기간 입력 → 상태 `승인대기`
2. **관리자 승인** (`#/admin`) – 승인 / 반려(사유 선택 또는 직접 입력) / 승인 취소 / 게시 중단
3. **결제** (`#/pay/:id`) – 승인된 건만 결제 가능. 결제수단 선택 → 결제 완료 시 즉시 `광고중`
4. **게시** (`#/`) – 결제 시점부터 선택한 일수만큼 한줄광고 목록에 노출, 기간이 지나면 자동 `종료`

내 신청 현황은 `#/my`에서 확인하며 승인 전에는 수정·취소, 반려 시 수정 후 재신청할 수 있습니다.

## 데모 동작 방식

- 로그인·서버가 없으므로 모든 데이터는 브라우저 `localStorage`(`bobae.oneLineAds.v1`)에 저장됩니다.
- 상단 **관리자** 스위치로 관리자 화면을 열 수 있습니다. 실제 서비스에서는 로그인 권한으로 대체해야 합니다.
- 결제는 모의 처리입니다. 실제 PG 연동 시 `bindPay()`의 결제 완료 처리 부분을 결제 승인 콜백으로 바꾸면 됩니다.
- 관리자 화면의 **데모 데이터 초기화**로 샘플 상태로 되돌릴 수 있습니다.
